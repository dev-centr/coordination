= Changelog
:toclevels: 3

== 2026-11-13

=== Serve starts in the background

* `agent-coordinator serve` detaches. It prints the id, the process id, the terminal that started it, `serve stop 1`, and the log path.
* `serve -listen` stays in this window. `serve status` lists every instance. `serve stop 1` and `serve stop server 1` stop one. `serve stop` stops all of them.
* One manager tracks those instances and exits when the last one is gone.
* Two listeners can open the same database file. It uses WAL so a second process waits instead of failing at once.
* Detail: link:changelog-details/2026-11-13%20-%20serve-background.adoc[Serve starts in the background].

=== Import keeps an omitted plan

* `plan import` can run again after the first load. An omitted `plan` field is stored as an empty string, not as a null that the node table rejects.

== 2026-11-12

=== Help is prohelp

* `agent-coordinator ?` renders `help/agent-coordinator.sdl` through the prohelp library. The help text is not a second copy in the program.
* A flag may use one dash (`-board`) or the older two-dash spelling.

=== Agent coordinator command

* The command is `agent-coordinator`. `plan` is the tree. `schedule wait` writes the wait on a plan step.
* `agent-coordinator serve` opens the database and the browser on port 17359.
* The column view on port 17358 still reads its JSON files when this database is down. Those files are not the routine ledger.
* Detail: link:changelog-details/2026-11-12%20-%20agent-coordinator-command.adoc[Agent coordinator command].

=== Coordination store

* The plan tree is the record an agent opens. A wait row points at a plan node and keeps the estimate, the status, and the wait-hub id.
* `coordinationd` on port 17359 serves that database, a local browser, and a hosted API that requires a Dev-Centr hosted token.
* `coordination` is the thin command: import, tree, wait, record-move, resolve, repair, and doctor.
* Transcript folders stay aliases of the first chat id. A missed link returns a hint instead of looking like a deleted chat.
* Detail: link:changelog-details/2026-11-12%20-%20coordination-store.adoc[Coordination store].

=== First-run help

* Running `coordination` with no arguments leads with what the program stores and the three commands to try first.
* The full command list stays on that screen, under Look and edit, When a chat folder was renamed, and Other.
